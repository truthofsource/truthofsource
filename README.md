## About my work

At **Efficient Supports**, I designed and built an Azure platform that brings employee onboarding, documentation, timesheets, shift notes and payroll review into one environment. It replaced disconnected paper and email processes with controlled digital records and consistent review steps.

My day-to-day work spans **Microsoft Entra ID and Microsoft Graph**, **Terraform**, **Azure Functions and Node.js**, **GitHub Actions**, and production troubleshooting. I work across application code and infrastructure, from a user's sign-in through API permissions, private storage, deployment and recovery.

## Engineering highlights

- **Identity lifecycle and application access:** Automated employee account provisioning with Microsoft Graph and integrated Entra ID sign-in with server-side token, role and record-ownership checks.
- **Secure cloud delivery:** Used GitHub Actions OIDC federation, scoped cloud permissions and reusable Terraform modules. Added vulnerability and secret scanning, verified artifact promotion and rehearsed rollback.
- **Protected employee records:** Implemented encrypted sensitive fields, private document handling, malware-scan gates and electronic W-4 signing with protected PDFs and separate applicant/staff access.
- **Business operations automation:** Built timesheet and shift-note review, attendance notifications, provider report imports and recovery paths. Added Shift Notes in response to a state survey finding about incomplete documentation.
- **AI-assisted employee badges:** Built portrait preparation, fixed-template badge rendering, printing, issuance, reprints, revocation and protected employee downloads.
- **Engineering knowledge and recovery:** Created an Entra-protected Backstage portal with TechDocs, scoped GitHub Apps, backup procedures and an on-demand VM operating model.
