## About my work

I designed and built an **Azure workforce and operations platform** for a healthcare services organization. My day-to-day work spans **Microsoft Entra ID and Microsoft Graph**, **Terraform**, **Azure Functions and Node.js**, **GitHub Actions**, and production troubleshooting. I work across application code and infrastructure, from a user's sign-in through API permissions, private storage, deployment and recovery.

## Networking and security

- **Network segmentation:** Designed hub-and-spoke connectivity, VNet peering and separate workload subnets, with NSGs controlling permitted traffic.
- **Private service access:** Configured private endpoints and Azure Private DNS for selected SQL and storage paths. Troubleshot name resolution, routing, TLS and service permissions as separate parts of the connection.
- **Keyless access:** Used managed identities and scoped roles for application access to Azure services, plus GitHub Actions OIDC federation for deployments without stored cloud passwords.
- **Encryption and key custody:** Built envelope encryption with AES-256-GCM and Key Vault-backed RSA-OAEP-256 key wrapping for sensitive employee and payroll fields, with retained key versions supporting historical records.
- **Malware-controlled uploads:** Connected Defender for Storage scan results to Event Grid, queues and a dedicated processor. Restricted previews and downloads until the result matched the stored file and its authorized record.
- **Posture review and investigations:** Reviewed Defender for Cloud recommendations and resource configuration. Used Application Insights, Log Analytics, KQL and storage/Key Vault audit logs to investigate authentication, access and processing failures.

## Engineering highlights

- **Identity lifecycle and application access:** Automated employee account provisioning with Microsoft Graph and integrated Entra ID sign-in with server-side token, role and record-ownership checks.
- **Secure cloud delivery:** Used GitHub Actions OIDC federation, scoped cloud permissions and reusable Terraform modules. Added vulnerability and secret scanning, verified artifact promotion and rehearsed rollback.
- **Protected employee records:** Implemented encrypted sensitive fields, private document handling, malware-scan gates and electronic W-4 signing with protected PDFs and separate applicant/staff access.
- **Business operations automation:** Built timesheet and shift-note review, attendance notifications, provider report imports and recovery paths. Added Shift Notes in response to a state survey finding about incomplete documentation.
- **AI-assisted employee badges:** Built portrait preparation, fixed-template badge rendering, printing, issuance, reprints, revocation and protected employee downloads.
- **Engineering knowledge and recovery:** Created an Entra-protected Backstage portal with TechDocs, scoped GitHub Apps, backup procedures and an on-demand VM operating model.
